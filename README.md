# SnapNotes: On-Device AI Meeting Summarization Assistant

Built for the **Snapdragon® AI Lab Build & Present Challenge**, SnapNotes is a localized workspace productivity tool designed to transcribe system or environment voice streams offline and instantly extract high-value summaries and checkbox action logs.

## Core Features
- **100% On-Device Privacy:** Zero external network communication hooks ensure data protection bounds are strictly kept locally.
- **Snapdragon NPU Acceleration:** Integrated with the **Qualcomm Neural Network (QNN)** Execution Provider context layers, ensuring high efficiency execution frames.
- **Native Energy Preservation:** Architecture prevents high battery drain curves on target HP portable computers.

## Running the Core Application App Interface
1. Clone this repository locally.
2. Install the necessary baseline software prerequisites:
   ```bash
   pip install -r requirements.txt
   ```
3. Boot the native interface execution framework:
   ```bash
   python app.py
   ```
